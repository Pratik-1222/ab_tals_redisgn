# ABTalks — AI Usage Log

## Tools
- **ChatGPT:** planning, scaffold, landing, dashboard, Challenge Day, edge cases, responsive polish.
- **Gemini:** UX ideation, reference-video analysis, redesign differentiation, visual/motion prompt generation.
- **Antigravity:** implementation, refinement, debugging, animations/interactions and consistency heatmap.

## Gemini → Antigravity workflow
Gemini was used to explore and describe UX/design directions. Those directions were converted into implementation prompts and pasted into Antigravity. Results were inspected; successful changes were retained and broken or undesirable experiments were reverted/refined.

## Feature mapping
1. Product planning and React/Vite foundation — ChatGPT.
2. Landing/dashboard/challenge flow — ChatGPT.
3. UX differentiation and reference-video analysis — Gemini.
4. Editorial preloader/typography/card/timeline/form directions — Gemini → Antigravity.
5. Philosophy/Mission experiments and stability resets — Gemini → Antigravity.
6. Cursor/liquid/spotlight experiments — Gemini → Antigravity.
7. 60-Day LeetCode/GitHub-style consistency heatmap — Antigravity, based on the documented UX direction.

## Integrity
This log does not claim that every line of final code was generated by one AI tool. It does not claim that every experiment remained in the final project. It does not fabricate prompts, timestamps or Git history.
