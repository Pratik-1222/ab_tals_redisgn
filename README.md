# ABTalks Redesign (scaffold)

This is a mobile-first React + Vite scaffold for the ABTalks 60-day challenge redesign. It includes three routes: `/`, `/dashboard`, and `/day/12` and uses mock data.

Quick start:

```bash
cd abtalks-redesign
npm install
npm run dev
```

Open `http://localhost:5173` and view the routes.

Files of interest:
- `src/pages/Landing.jsx`
- `src/pages/Dashboard.jsx`
- `src/pages/ChallengeDay.jsx`
- `src/data/mockData.json`
- `PROMPTS.md` (AI usage log)
